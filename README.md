# Informe Branding — Club Atlético Talleres

Reporte mensual interactivo de Diseño, Fotografía y Producción.

## Uso
Abrir `index.html` en el navegador, o publicarlo con GitHub Pages (Settings → Pages → rama `main`, carpeta raíz).

## Archivos
- `index.html` — informe
- `datos.js` — datos mensuales por área
- `support.js` — runtime del componente
- `_ds/` — estilos y tipografías
